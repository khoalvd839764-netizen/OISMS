## B02-F01 — P1 — Kết nối Hub đang start sống qua logout và chặn phiên mới

- AC: T03-AC-01, T03-AC-05.
- Source: `src/frontend/pos-app/src/services/realtimeService.ts:226`, `:287`, `:350–351`, `:396–406`.
- `conn` chỉ được gán vào singleton sau `await conn.start()`. Khi A còn connecting, stop/logout không có connection để dừng; start của B bị `if (isStarting) return` bỏ qua. Khi start A hoàn tất muộn, A vẫn join branch cũ và callback phát tới tập listener hiện tại mà không kiểm tra generation/owner.
- Repro trên handler production, transport điều khiển: start A chờ → logout/stop → token B/start B → cho A hoàn tất → phát OrderCreated từ connection A. Kết quả: chỉ tạo 1 connection, A chưa từng bị stop, listener sau đổi phiên nhận `PRIVATE-A-ORDER`. Đây là lỗi cô lập callback phiên; không khẳng định đã thử rò dữ liệu tenant trên backend thật.
- Đóng khi: start/stop/đổi token/user/tenant/branch được phân xử theo context hiện hành; connection đang khởi tạo cũng được thu hồi; completion/callback/close/reconnect cũ không sửa trạng thái hoặc gửi event vào phiên mới; B thực sự kết nối. Có regression cho deferred start và logout/đổi phiên giữa await.
