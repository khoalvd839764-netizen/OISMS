- **Ngày:** 2026-11-21
- **Commit nền:** `879a1ef` (+ sửa `docker/caddy/Caddyfile`)
- **Môi trường:** Container `caddy:2.10-alpine` nối vào `oisms_oism_network` với `ADMIN_DOMAIN=admin.localhost`, `POS_DOMAIN=pos.localhost`, `SIM_DOMAIN=sim.localhost`, cổng `8443:443`.

## Kết quả

1. `openssl s_client -connect 127.0.0.1:8443 -servername admin.localhost -tls1_3` → **Thành công** (`Protocol: TLSv1.3`, `Cipher: TLS_AES_128_GCM_SHA256`). Output: [`openssl-tls13.txt`](./openssl-tls13.txt).
2. `openssl s_client -connect 127.0.0.1:8443 -servername admin.localhost -tls1_2` → **Bị từ chối** (`tlsv1 alert protocol version`, `Cipher: (NONE)`). Output: [`openssl-tls12.txt`](./openssl-tls12.txt).
3. `curl -sk -i --resolve admin.localhost:8443:127.0.0.1 https://admin.localhost:8443/health/live` → `HTTP/2 200` (`{"status":"Live",...}`). Output: [`curl-health-live.txt`](./curl-health-live.txt).
4. `curl -sk -i --resolve admin.localhost:8443:127.0.0.1 https://admin.localhost:8443/health/ready` → `HTTP/2 403` (chặn hoàn toàn). Output: [`curl-health-ready-caddy.txt`](./curl-health-ready-caddy.txt).
5. `curl -sS http://localhost:5000/health/ready` (nội bộ) → `200 Healthy` (51 bảng). Output: [`internal-health-ready.txt`](./internal-health-ready.txt).
