# Bằng chứng kiểm thử — OISMS-66-FIN-B (`FR-REP-01` Admin bộ chọn SKU)

- **Ngày:** 2026-11-21
- **Commit nền:** `879a1ef` (+ `FIN-A` và `FIN-B`)
- **API tìm SKU đã chọn:** `apiAdapter.getSkus()` (`src/frontend/admin-dashboard/src/services/apiAdapter.ts`).

## 1. Build GATE

- Lệnh: `npm run build --prefix src/frontend/admin-dashboard`
- Kết quả: Thành công (`tsc -b && vite build`, `0` lỗi).

## 2. Đối chiếu UI/API trên Admin local (`http://localhost:5173`)

1. **Lọc 1 SKU (`POLO-NAM-DEN-M` — `11111111-0000-0000-0006-000000000001`) & F5:**
   - UI & API khớp 100%: `revenue = 1.794.000 đ`, `returnAmount = 299.000 đ`, `netRevenue = 1.495.000 đ`, `netCogs = 600.000 đ`, `grossProfit = 895.000 đ`, `totalOrders = 3`, bảng `skuBreakdown` 1 dòng (`6 Cái`).
   - F5 giữ nguyên `?skus=...` và lựa chọn; khối `daily-sales-summary-section` bị ẩn.
   - Ảnh: [`screenshots/fin-b-1-sku.png`](./screenshots/fin-b-1-sku.png).
2. **Lọc nhiều SKU (`POLO-NAM-DEN-M` + `POLO-NAM-TRANG-L` — `bb99eb0f-bcf0-d9ad-36ca-36cf5bf987de`):**
   - UI & API khớp 100%: `revenue = 2.073.000 đ`, `returnAmount = 299.000 đ`, `netRevenue = 1.774.000 đ`, `netCogs = 680.000 đ`, `grossProfit = 1.094.000 đ`, `totalOrders = 3`, bảng `skuBreakdown` 2 dòng (`6 Cái` và `1 Cái`).
   - Ảnh: [`screenshots/fin-b-2-skus-table.png`](./screenshots/fin-b-2-skus-table.png), [`screenshots/fin-b-2-skus-kpi.png`](./screenshots/fin-b-2-skus-kpi.png).
3. **Bỏ lọc SKU:**
   - `sku-breakdown-section` biến mất, `daily-sales-summary-section` hiện lại, `?skus=` bị xóa khỏi URL.

## Giới hạn

- Tài khoản `owner@shopa.local` trên DB demo local chỉ có tổng cộng **2 SKU**, nên ca lọc nhiều SKU kiểm chứng với 2/2 SKU hiện có (thay vì 3 SKU).
